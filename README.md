# Rust By Examples Extended Version

In this rust-by-examples repository, topic list is extended and detailed Turkish and English line comments with explanation were added.
Also references for topics included.

## How to Install?

Just **clone** the repository with the command given below:

```bash
git clone https://github.com/gokayburuc/extended-rust-examples.git
```

Then `cd` into the repository path and check the repo with your favourite text editor (VSCode, Neovim, VIM, Helix Editor etc.)

## How To Execute?

Please add the script file with function name to `main.rs` and then :

```bash
cargo run 
```
